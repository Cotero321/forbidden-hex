# Forbidden Hex 视觉资源规范

适用基线：Minecraft 1.20.1、Forge 47.4.10、Java 17、官方 mappings。美术方向为接近原版的像素风：旧木、暗铁、草药、石材、烟灰与少量仪式亮色。用户后续要求跳过实体和祭坛，本轮不对这两类素材作美术改造。

## 素材归属与尺寸

- 人工 PNG 和专属设备模型归入 `src/main/resources/assets/forbidden_hex`。`src/generated/resources` 保留适合自动生成的模型和玩法数据；两个资源根不允许同路径重复。
- 独立物品图标及动画单帧为 16×16；重点设备纹理为 32×32。GUI、粒子、字体、方块及其他世界纹理按用途确定尺寸，不套用物品图标规则。
- 方块模型 UV 采用 Minecraft 的 0～16 坐标；32 像素纹理不代表 UV 上限为 32。逐面检查比例与接缝；已有 `_uv` 文件是实际附加材质，不能当作可删除的编辑器参考图。
- 保持 `forbidden_hex` 命名空间及既有运行时路径，避免纯外观统一引发存档或引用改名。第三方 VFX 许可与来源保留在 `META-INF/third_party_notices.txt`。

## 像素与轮廓

- 使用清楚的轮廓、方向一致的像素簇和大块明暗，减少随机噪点；原尺寸先辨认，最近邻放大用于检查。
- 草药四阶段通过叶型、花穗、果实、根部和生长姿态表达成熟度，种子与产物与植物对应，不只替换颜色。
- 树种通过树皮结构、年轮、叶型和枝叶疏密区分；设备的高光、磨损、烟灰与构造及工作面对应。
- 玻璃层和内容染色层保持分离；法杖独立图标与组装部件保持材料、品质和源色关系。

## GUI 与表现契约

- 沿用既有界面布局和知识节点。秘典底图为 512×288；五枚原创徽记为 32×32；状态图标为 18×18；插槽为 16×16；符文字体图集为 192×48。
- 秘典书底按现有切片契约采样，尺寸正确不等于缩放后画面已合格。切角遮罩避免重复覆盖半透明像素，悬停遮罩应覆盖图标回退路径。
- 徽记的透明轮廓可以一致，内部图案必须按彩色像素实际比较。不得仅据 alpha 轮廓相同覆盖已有原创素材。
- 资源重载只发布待处理标记或版本号，缓存失效及渲染状态变更按既有客户端线程时序处理。秘典每个实例在下次绘制时消费重载版本，使正文行数与画布字体包围盒一并失效，并保留各族平移。

## 魔法与光影

- 形成蓄力汇聚、载体成形、运动尾迹、命中爆发和短暂余韵的层次，保留源、墨、载体的身份关系与真实落点。
- 装饰粒子受每 tick 配额约束；酿造 `particleBudget` 保持原有含义，法术使用独立 `spellParticleBudget`。远处和低粒子档优先删减纹样、光丝和多层透明装饰，保留主要轮廓。
- 发射在 tick/事件侧完成，不随渲染帧率加倍。世界切换清理自有队列；环形粒子根据实际生成位置做距离门控。
- 共用 `ClientShaderCompatibility`。光影 ACTIVE、状态未知或强制兼容时使用原版渲染回退，不抢占外部 FBO 或关闭外部后处理。

## 参考来源与证据

旧版参考为用户提供的 `witchery-1.7.10-0.24.1.jar`。`build/visual-review/witchery-reference.json` 记录 ZIP 条目、尺寸和哈希，原 JAR 保持不变，参考图片仅在开发审查目录使用。

已知证据支持纹理尺寸、轮廓和氛围对照；图片本身不能证明旧模型 UV 正确。参考报告中标记的旧版模型字节码/三维 UV 检查不视为已完成。本项目专属模型以自身逐面 UV、资源引用和实际游戏画面作为验收依据，不照搬旧版模型、玩法映射或数值。

## 维护入口

先通过 `python -m pip install -r tools/requirements.txt` 安装 Pillow。`tools/visual_resources.py audit --previews` 检查两个资源根，清单、摘要和分组前后图集均输出到 `build/visual-review`，不覆盖正式素材，也不把机器报告提交到仓库。`snapshot` 不覆盖既有 baseline。

`tools/audio_synth.py --verify` 需要 PATH 中可用的 FFmpeg 与 FFprobe，检查 54 个事件、96 个 OGG 的原始 Vorbis/单声道/采样率、解码及峰值。省略 `--verify` 会重新合成并覆盖法术音效。

`tools/visual_resources.py particle-edges` 只核对两张已限定的黯系粒子外缘；追加 `--fix` 才会写素材，并在 `build/visual-review/particle-edge-backup` 保留首次备份。两像素邻域仅表示透明邻近，不等于外部连通域，素材结构改变后需重新确认内核保护。

`visual_botanicals.py`、`visual_equipment.py`、`visual_items.py`、`visual_gui.py` 是素材生成/绘制工具，执行会覆盖对应正式文件，不能用作只读核对。完整命令、运行结果和未验证项见 `acceptance.md`。
